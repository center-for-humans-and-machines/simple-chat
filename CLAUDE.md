# CLAUDE.md

## Pull requests

- Tasks are tracked in Linear, team `simple-chat`, with ticket IDs like `SIM-11`.
- PR titles start with the ticket ID and a colon, for example
  `SIM-11: Add "Simple Chat as a Service" section to README`, so the PR list
  shows which ticket each PR handles. A PR for several tickets lists them all
  (`SIM-5, SIM-19: …`). Do not repeat the ID at the end of the title.
- PRs without a ticket, such as Dependabot updates, keep their titles.
